# Maintenance Manager – Power & AC Dashboard

## Project Overview

**Maintenance Manager** is a web-based dashboard designed to monitor and manage preventive maintenance activities for power and air conditioning equipment across multiple sites.

The system helps maintenance teams track equipment, monitor upcoming maintenance tasks, identify overdue work, and update maintenance records from a centralized dashboard.

## Key Features

- **Dashboard Overview** – View total equipment, upcoming maintenance, overdue tasks, and on-track equipment.
- **Equipment Management** – Register and manage equipment across multiple sites.
- **Maintenance Scheduling** – Track maintenance schedules and next due dates.
- **To-Do List** – Identify pending maintenance activities.
- **Maintenance Updates** – Update completed maintenance tasks.
- **Reports & History** – Review maintenance activities and previous records.
- **Site Management** – Organize equipment by location or branch.
- **Administration** – Manage system users and administrative activities.

## Project Goal

The main objective is to improve maintenance planning, reduce unexpected equipment failures, avoid missed maintenance schedules, and improve the overall reliability of power and AC systems.

## Technologies

Python, Django, PostgreSQL, HTML, CSS, Bootstrap and JavaScript
